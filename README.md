# DLcatalysis

Deep-learning model for predicting enzyme catalytic efficiency
(kcat/Km) from protein sequence, substrate SMILES, and EC number.

## Architecture

Five complementary feature streams feed a three-branch regression head with
cross-attention and a learned dynamic gate:

- **ProtT5** (frozen, residue-level, 1000 x 1024)
- **Morgan** fingerprint (radius 2, 1024 bits)
- **MolT5** sentence embedding (768)
- **GROVER** chemical graph fingerprint (4885)
- **EC number** four-level embedding

Cross-attention couples enzyme residues with substrate modality tokens, and a
gating MLP scales the substrate and interaction branches against the
sequence-only baseline.

## Loss

```
L = L_logcosh + lambda_pcc * (1 - PCC) + lambda_enz * L_rank^enz + lambda_sub * L_rank^sub
```

## Layout

```
config/                model + training config
src/
    model/             EnzSub model + modules
    util/              data module, tools
    tools/             training entry, inference (5 features)
train/
    run_train.py       10-fold CV trainer
    run_bayes.py       Bayesian HPO worker

```

## Quick start

Install requirements (Python 3.10+, PyTorch >= 2.0):

```bash
pip install -r requirements.txt
```

GROVER is required as a side-checkout; it is intentionally not vendored:

```bash
git clone https://github.com/tencent-ailab/grover other_softwares/grover_software
```

Train (10-fold cross-validation):

```bash
cd train
python run_train.py --config ../config/config.yml --cv \
    --fold_dir ../DataSet/final_data --output_dir cv_results
```

Inference (10-fold ensemble):

```bash
cd src/tools
python infer.py --config ../../config/config.yml \
    --ckpt_dir ../../train/best_ckpts \
    --input ../../input.xlsx \
    --output ../../predictions.xlsx
```
